
# Personal Expense Tracker

A simple command-line application built with Python to manage personal expenses.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Group expenses by category
- Delete expenses
- Simple command-line menu

## Requirements

- Python 3

## How to Run

1. Clone the repository.
2. Open the project directory.
3. Run the following command:

   python main.py
